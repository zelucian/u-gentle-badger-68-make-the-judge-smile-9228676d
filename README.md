One line about a small good thing that happened today: the warteg auntie slipped an extra fried egg onto my rice and whispered, "for the early bird" — an egg I never ordered, eaten like a gift. `main.ts` writes exactly that line to `entry.txt`.

## Run it

```sh
node main.ts
```

This writes `entry.txt` to `/output` (or `$MAKEFUN_OUTPUT_DIR` when set). The program is deterministic, makes no network calls, and validates the line first: 1–200 characters, trimmed, a single line.
